# Origin

This repo exists to show that Kinetic Gain's control-plane pattern extends cleanly into robotics and fleet operations.

The primitive is not generic "robot monitoring." The real workflow pressure lives in:

- mission failures that block redeploy
- manual override packets waiting on review
- replay evidence gaps after an incident
- named owner accountability before the next autonomous window

`robot-fleet-exception-board` packages that pressure into a buyer-readable and operator-readable public surface.
